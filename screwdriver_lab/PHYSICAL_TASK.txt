PHYSICAL SCREWDRIVER TASK — OCTOBER 15, 2026

Current scope
The CPU MuJoCo task uses explicit mating thread contact and bounded robot
actuators. It does not apply tool/screw forces, ideal gravity compensation,
pose corrections, or a helical equality. Newton/MuJoCo-Warp on physical GPU 1
is an additional backend under development. A 4 kHz collision-refresh run
now reaches pickup and bit engagement; full GPU screw-in remains unverified.
RTX video replay uses Blender Cycles + OptiX on physical GPU 1 (PCI 61:00).

Task strategy
approach -> pinch -> lift / in-hand pivot -> index-cap support -> align bit
-> contact-observed engagement -> drive / loaded return -> seat / hold.
The graph uses Python code nodes and observation-conditioned exits, following
the general Graph-as-Policy structure without its harness. The in-process
node/route descriptions are not claimed to be drop-in GaP workflow files.
It is not a runtime LLM controller. Exact simulator contact/pose sensing is assumed.

Metrics
Raw 1 kHz observations: load >0.01 N marks contact; signed relative slip
<-0.1 mm/s marks return sliding. Both contact and sliding fractions are
reported during commanded return motion. Also report net/backward screw
rotation, insertion, tilt, bit engagement, force, penetration and motor limits.
A seating verdict requires depth >=1.98 mm, bit engagement, screw speed
<0.15 rad/s and head/workpiece force >0.1 N for 0.4 s. Timeouts are failures
to complete within the budget, even if there is positive insertion.

Model assumptions / limitations
The 24 mm, 53.5 g synthetic tool and engineered pickup supports are not a
calibrated reconstruction of the source tool. The screw is an 8 g six-DOF
body; explicit 1 mm-pitch trapezoidal thread sectors generate axial advance.
The initial screw is already aligned in the female thread. Cross-threading,
arbitrary hole finding, final tightening torque and hardware transfer are
not established. The requested task here is 2 mm advancement and seating.
40 Shore A silicone motivates a ~1.69 MPa modulus estimate and a circular
Hertz soft-finger torsion approximation. This is not validated hydroelastic
pad deformation. Friction, backing, damping and motor dynamics remain
uncalibrated. Generic joint damping/armature remain declared model assumptions.
Finger effort is capped at 0.11 Nm, including compensation, held at 500 Hz.
Normal contact solref=.004; impratio=100; CPU libccd convex collision.
